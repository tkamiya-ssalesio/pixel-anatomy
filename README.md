# 画素の解剖器

情報Ⅰ「情報のデジタル表現」第5回（実教出版『最新情報Ⅰ』第3章 1-4 画像の表現，1-5 画像のデータ量）の授業用シミュレータ．画像を画素のひとつひとつまで拡大して調べ，色のつくり方・画素の数・色の段階・データ量を変えたときの画像の変化を確かめる．

公開URL：（公開前．公開したらここに書く）

## できること

- **色をつくる**（`#color`）：R・G・B を 0〜255 で決め，各色を16進数（2桁）・10進数・2進数（8ビット，4桁ずつ区切り）で同時に見る．`#RRGGBB` の全体表示と24ビットの2進列，色見本つき．カラーコード（6桁）の直接入力欄は，既定では隠れていて，「カラーコードから調べる（解いたあとで）」にチェックを入れたときだけ出る（入れると R・G・B が変わる．S3 で手で解く前に答えが出ないようにするため）．
  - 答え合わせ欄：「めざす色コード」を入れておくと，いまの R・G・B から作った16進数が同じなら「一致」，違えば「まだ違う」と出る．めざす色の見本の四角も出る．直接入力欄から入れた値で一致させたときは「カラーコードから入れた値です」と注記する
  - 光の重なりスイッチ：赤・緑・青の円を重ね，各円の明るさは R・G・B の値に連動する（加法混色．重なりはイエロー・シアン・マゼンタ・白になる）．切るとふつうの重ね描きになる
  - 表示する式：8ビット × 3 ＝ 24ビット，2²⁴ ＝ 16777216 色（256 × 256 × 256），FFFFFF ＝ 白，000000 ＝ 黒．色の例のチップ（赤・緑・青・イエロー・シアン・マゼンタ・白・黒）
- **画素を調べる**（`#pixel`）：見本の一部を 20×15 マスに拡大して，画素を1マスずつ見せる．全体の縮小図に表示範囲の枠が出て，押す・なぞる・矢印キー・ボタンで動かせる．マスを押すと，座標（左上が (0, 0)）と RGB（16進・10進）と色見本が出る．格子線は入切できる
- **解像度と階調**（`#resolution`）：同じ画像を A・B の2枚で並べ，**解像度**（元の 1/1・1/2・1/4・1/8・1/16・1/32）と**階調**（各色 2・4・16・256段階．1・2・4・8ビット）を別々に動かす．カードごとに横×縦の画素数，1画素のビット数，段階数，データ量（約○KB／MB）を出す．初期状態は A＝1/8・256段階，B＝1/1・4段階（2ビット）
  - 「この粗さで確定」：そのカードの画像を，いま作業中の元画像に置き換える（そのカードのスライダーは最大に戻る）．確定後に解像度・階調を最大にしても粗いまま＝捨てた分はもどらない．「もとの写真にもどす」で初期化する
  - 色のモード（A・B 共通）：カラー／白黒・グレー（後述）
  - 「数字をかくす」（教員用）：データ量・画素数・ビット数・段階数を隠し，「解像度」「階調」を「区切りの細かさ」「段階の細かさ」に置き換える．タブ名は「画像を粗くする」になり，この画面を開いている間は，リード文の「データ量」とタブ「データ量」も「大きさ」に置き換わる（画面の可視テキストに「データ量」「解像度」「階調」は残らない）．予想の前に使う導入用
- **ラスタとベクタ**（`#zoom`）：同じ図形（円・三角形・斜めの線）を，ラスタ形式（64×64 画素の格子に描いたものを拡大）とベクタ形式（座標と数式から，その倍率で描き直す）で並べて 1・2・4・8・16・32 倍に拡大する．拡大位置は図形の縁の付近が初期値で，なぞる・ボタン・矢印キーで動かせる．ラスタ側は何×何画素か，ベクタ側は図形を表す式（例：`円 中心(32, 32) 半径24 色 #22A391`）を出す
- **データ量**（`#data`）：横・縦の画素数（1〜20000）と1画素のビット数（24ビットフルカラー／8ビットのグレー／1ビットの白黒）から，`ビット数＝横×縦×ビット` → `÷8＝バイト` → `÷1024＝KB` → `÷1024＝MB`（1KB＝1024B，1MB＝1024KB）を順に展開する．あわせて教科書の形（`3×1024×768÷1024÷1024`）と，2のべき乗に分けた約分（`1024＝2¹⁰，768＝3×2⁸ → 3×3×2¹⁸÷2²⁰＝9÷4＝2.25`）を出す．割り切れないときは「≒」で小数第2位まで（さらに小数第1位）．「縦も横も2倍にする」ボタンと，基準にした値との比（「基準の4倍」）つき．結果だけの欄は作らず，展開を主役にしている

## 授業で使うときのURL

| URL の末尾 | 開く画面 |
|---|---|
| `#color` | 色をつくる |
| `#pixel` | 画素を調べる |
| `#resolution` | 解像度と階調 |
| `#zoom` | ラスタとベクタ |
| `#data` | データ量 |

- `?c=22A391#color`：「めざす色コード」を設定して開く．**めざす色の見本の四角だけが出て，R・G・B の値は 0 のまま**（答えが出ない）
- `?hide=1#resolution`：数字をかくした状態で開く（導入用．「区切りの細かさ」「段階の細かさ」の表示）
- `?w=1024&h=768#data`：データ量の画素数を指定して開く（1〜20000）．`?bits=24`（24・8・1）で1画素のビット数も指定できる

### Classroom に載せない注意

答えが出る指定は，生徒に配るURLに入れない．

- **`#data`**：既定が 1024×768・24ビット（設計書 §4.3 のとおり）で開くため，何も付けなくても 2.25MB までの展開が見える．S6 で手計算を終えてから開かせる（先に Classroom に載せない）．`?w=1024&h=768` と `?bits=24` も同じ答えが出る
- **`?c=22A391`（`#color`）**：めざす色コードが答えの6桁そのもの．入れると，R・G・B に10進数を入れて照合する活動の「めざす値」が画面に出る．導入（種明かし前）に配らない．教員の画面でだけ使う
- **`#color` のカラーコード直接入力欄**：既定で隠してある．チェックを入れると，スライドの6桁を打つだけで R・G・B と2進が出る．解いたあとの答え合わせで使わせ，導入・解く前は「カラーコードから調べる」にチェックを入れさせない
- **`#pixel` の図形・グラデーション**：マスを押すと RGB が出る．図形の色は教科書の例 `#22A391` を使っていない（答えが拾えないようにした）
- **`#zoom`**：ベクタ側の式とラスタ・ベクタ両方の色に `#22A391` を使っている（設計書には記述がなく，ラスタ・ベクタ側の色として採用した）．導入（種明かし前）に `#zoom` を開かせない
- 導入（予想の前）に配る `#resolution` は，`?hide=1` つきにする

## しくみ

- `index.html` 1ファイルで動く．外部のライブラリ・フォント・画像は使わない（Canvas だけ）．画像はこのブラウザの中だけで処理し，どこにも送信しない
- 見本の画像は，すべてコードで描く（`Math.random` は使わず，毎回同じ絵になる）．「校舎と空」（800×600．空のなめらかなグラデーション，雲，校舎，木，地面．人・顔は描かない．空のグラデーションは，階調を落としたとき縞が出るようゆるやかに変えている）・「グラデーション」（R・G・B の帯と明るさの帯）・「図形」（輪郭のはっきりした色の図形）．権利の問題がない
- 自分の画像を読み込める（`<input type="file" accept="image/*">`）．長い辺が800画素になるよう縮小して使う（それより小さい画像は拡大しない）．「画素を調べる」と「解像度と階調」で共通の元画像を使い，切り替えは両画面で同期する
- 縮小は**最近傍**：縮小後の各マスの中心にあたる画素の値をそのまま取り出す（ぼかさない）．拡大表示は，元の大きさに画素のマスのまま引き伸ばす（`imageSmoothingEnabled=false`）．ただし表示する画面の幅より画素の数が多い場合（解像度 1/1・1/2 のとき）は，画面に収めるためだけに，なめらかに縮めて見せている
- 階調は，各色（0〜255）をいちばん近い段階の値に丸める．ディザはかけない
- **色モードの判断**：カラーのときの1画素のビット数＝3×（各色のビット数）．各色2段階のカラーは8色の画像になる．設計書の「1ビット＝白黒」を成り立たせるため，「白黒・グレー」のときは輝度（0.299R＋0.587G＋0.114B）を階調の段階数で丸め，2段階＝白黒（1ビット/画素），256段階＝グレースケール（8ビット/画素）として示す
- 「確定」した画像は，縮小した画像を元の大きさ（800×600 など）に引き伸ばしたもので，画素の数は同じだが，同じ値のマスが並んでいる．データ量は，確定後の元画像を基準に計算する
- 「ラスタとベクタ」のラスタ側は，64×64 の格子の各画素の中心が図形の内側かどうかで塗り分ける（ぼかさない）．ベクタ側は，同じ式から Canvas の描画命令でその倍率のまま描き直す
- データ量は 1024進．整数だけで割り切れるかを判定して「＝」「≒」を出し分けている
- タッチ・Chromebook でも動くよう pointer イベントで作っている．幅 360px でも横にはみ出さない．`prefers-reduced-motion` のときは動きを止める

- 空のグラデーションを階調4ビット（16段階）に落としたときの縞の見え方（画面の違いで見え方が変わる）
- 「校舎と空」の見た目（授業の「校舎と空」の写真として問題ないか）
